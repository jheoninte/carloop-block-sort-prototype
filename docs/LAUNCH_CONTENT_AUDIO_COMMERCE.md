# 콘텐츠·연출·사운드·수익화 구현 현황

2026-11-17. 그래픽 교체는 후속 작업으로 유지했습니다. Windows에서 게임 흐름을 구현하고 검증했으며, 실제 StoreKit/광고 SDK 연결과 실기기 검증은 Mac 단계에 남았습니다.

## 300레벨 캠페인

- 사용자가 선택한 계획 기준은 30일 × 하루 10레벨 = 300레벨입니다. 날짜 제한이나 하루 플레이 제한은 없습니다. 한 달의 이용 기간이나 리텐션을 보장하는 수치가 아닙니다.
- 검토한 기존 20레벨을 그대로 보존하고 21~300을 재현 가능한 구성 생성기로 추가했습니다. 색상별 수량, 해법, 튜토리얼 연결을 검증했습니다. 신규 280개는 사람의 검수를 마친 수작업 레벨이라는 뜻이 아닙니다.
- 신규 배치는 차선을 무시하고 색 이름을 일관되게 바꿔도 같은 차량 용량/블록 배열이 나오면 제외합니다. 모든 그래프 동형이나 인간이 느끼는 반복감까지 판정하지는 않습니다.
- 3~6대 차량, 2~3색, 다른 용량·혼합 앞 블록·목표 색 꼬리·사출 순서와 트랙 용량을 조합합니다. 표기 난이도 2~5는 생성 가설이며 학습된 인간 난이도가 아닙니다.
- `campaign_manifest.json`의 30개 묶음은 제작/QA 계획 데이터입니다. 게임이 날짜별로 잠그거나 매일 접속을 강제하지 않습니다.
- 자동 정책의 전체 사출은 2,376회, 1x 재생은 9,632.47초입니다. 4.2초 대기 정책의 결과이므로 사람의 소진 시간으로 환산하지 않습니다.
- HTML과 Godot이 같은 300레벨 JSON을 사용합니다. Godot 세이브 v5는 레벨 ID 기반으로 추가·재정렬에 대응하고, 규칙이 바뀐 현재 레벨만 다시 시작하며 완료 기록을 유지합니다. 알려진 v4도 변환합니다. 상세 범위는 `docs/SAVE_MIGRATION.md`에 있습니다. 웹은 기존 프로토타입 저장 정책을 유지합니다.

재생성/검증/설치:

```powershell
.\tools\godot.ps1 campaign
.\tools\godot.ps1 levels -PackPath .tools/campaign-300.json
python tools/install_campaign.py .tools/campaign-300.json
.\tools\godot.ps1 pacing
```

`campaign_seed.json`이 검토한 첫 20레벨을 보관합니다. 생성기의 seed는 202611170300입니다. 설치기는 첫 20개 레벨·해법·튜토리얼 보존과 ID를 확인합니다. 실제 해법 검증은 반드시 설치 전 Godot 검사기로 수행합니다.

## 사운드와 연출

- 자체 합성한 원본 WAV 12개: 사출, 5단계 수집음, 차량 완성, 레벨 클리어, 막힘, 버튼, Undo, 배경 음악. 총 약 1.7MB입니다.
- 44.1kHz/16bit 모노 PCM, 어택/릴리스와 시작·끝 0 샘플을 사용합니다. 4개 효과음 플레이어, 80ms 수집 제한, 5음 변화, 완성음 우선순위로 과밀한 재생을 줄입니다.
- 배경 음악 16초 루프는 별도 플레이어로 재생하고 메뉴·앱 중단·광고 동안 멈춥니다. 효과음과 음악 음량/음소거를 따로 저장합니다. 설정 v1도 읽고 새 저장은 v2로 기록합니다.
- 수집 입구의 링/작은 입자, 차량 완성 강조, 클리어 축하 입자를 추가했습니다. 입자는 최대 64개로 제한하고 정지·취소·재시작·연출 줄이기에 대응합니다. 게임 코어에 입자나 사운드 상태를 넣지 않습니다.
- `python tools/build_audio.py`로 원본 음원을 재현합니다. 외부 음원·플러그인·생성 서비스·유료 자산을 사용하지 않았습니다. 가져오기 메타데이터의 무손실 PCM 설정도 저장합니다.
- 출시용 오디오의 최종 청감, iPhone 스피커/헤드폰 밸런스, 무음 스위치, 다른 음악과의 공존, 광고 오디오 복구는 Mac 실기기에서 확인해야 합니다. 현재 산출물을 검증 완료된 최종 마스터라고 주장하지 않습니다.

## 상점·광고·결제 흐름

- 상점에서 광고 제거 비소모성 구매, 구매 복원, 선택형 보상 광고, 건너뛰기 잔여 수량과 사용을 제공합니다. 스타터팩/유료 소모성 상품/재화 경제는 아직 추가하지 않았습니다.
- 광고 제거는 전면 광고를 제외합니다. 선택형 보상 광고는 남으며 구매 전에 표시합니다. 보상 광고를 이용하지 않아도 Undo와 다시하기로 무료 플레이를 계속할 수 있습니다.
- 전면 광고는 첫 5레벨을 제외한 레벨 완료 전환에서만 요청합니다. 완료 3회 및 120초 간격을 모두 만족해야 하며 광고 제거 권한이 있으면 요청하지 않습니다. 실패한 요청도 빈도 제한에 포함해 재요청을 줄입니다.
- 보상 완료 콜백에서 건너뛰기 1회를 저장합니다. 취소/실패/보상 없는 닫힘/오래된 응답은 지급하지 않습니다. 중복 콜백과 거래 ID를 처리합니다. 잔여 수량 상한은 99입니다.
- 건너뛰기는 별도 지갑에 예약을 먼저 저장하고 게임 저장 뒤 확정합니다. 중단 시 예약을 이어 처리하며 클리어 기록을 거짓으로 만들지 않습니다. 콘텐츠가 달라져 예약 대상이 사라지면 잔여 수량을 돌려줍니다.
- 확인된 비소모성 거래는 로컬 저장이 성공한 뒤에만 네이티브 거래 완료를 확인합니다. 저장 실패 시 미완료 거래를 재전달받도록 둡니다. 검증된 소유권 스냅샷으로 복원·환불/권한 취소를 반영합니다.
- Windows 디버그 상점에는 ‘실제 결제/광고 아님’ 표시와 성공·취소·실패·미연결·구매 승인 대기 시나리오가 있습니다. iOS/Android와 release 빌드에서는 모의 제공자를 강제로 끕니다.
- 실제 SDK가 없으면 미연결로 실패하고 권한/보상을 만들지 않습니다. Mac 작업은 아래 연결 계약을 만족하는 네이티브 어댑터 구현/연결부터 시작해야 합니다. 단순히 실기기 버튼만 확인하면 끝나는 상태는 아닙니다.

## 검증

- 게임·저장·튜토리얼·설정·오디오·입자 회귀 553개.
- 구매·복원·광고·저장 오류·중복·승인 대기·거래 완료 확인·UI/재시작 복구 검사 43개.
- 세이브 변환·레벨 변경·이전 백업 복구·알 수 없는 버전 보존·설정/지갑 분리 검사 112개.
- 300레벨 Godot 60/120Hz·1x/2x 1,200회, 웹 코어 1,200회, 1x/2x 템포 재생 600회 통과.
- Windows GUI에서 모의 구매, 광고 보상, 잔여 수량 사용, 레벨 이동과 음악/효과음 설정 화면을 확인했습니다. 실제 구매/광고는 실행하지 않았습니다.

일괄 검사는 `.\tools\godot.ps1 test`입니다. Mac 인계 계약은 `docs/MAC_PLATFORM_ADAPTER.md`를 참고하세요.
