# Game Design Spec

## 장르 정의
- `CarLoop: Block Sort` 계열의 Sort & Jam 하이브리드 캐주얼 퍼즐
- 색상 분류의 직관성과 길 막힘/병목 관리의 퍼즐성을 결합

## 코어 루프
1. 차량 배치와 트랙 여유 공간을 관찰한다.
2. 차량을 탭해 블록을 순환 트랙으로 사출한다.
3. 블록이 트랙을 돌며 조건에 맞는 차량에 자동 수집된다.
4. 같은 색이 가득 찬 차량은 클리어되어 퇴장한다.
5. 모든 차량을 정리하면 클리어한다.

## 초기 MVP 필수 요소
- 원탭 조작
- 순환 트랙 이동
- 자동 수집
- 차량 완성/퇴장
- 데드락 판정
- 2배속 토글
- localStorage 기반 실시간 저장

## 레벨 기믹 후보
- 앞차에 막힌 차량
- 미스터리 블록
- 잠금 차량
- 터널/차고 스폰
- 분기 트랙

## 수익화/메타 반영 포인트
- 실패 직전 부활
- Undo / Magnet / Shuffle / Extra Slot 부스터
- 광고 제거 + 영구 2배속 패키지
- 차량 스킨 컬렉션

## 아키텍처 원칙
- 레벨은 JSON 데이터로 관리
- 트랙 이동/자동 수집/데드락 판정은 뷰와 분리
- HTML5, Godot, Unity에서 재사용 가능한 상태 구조 유지
