# 플레이 진입 흐름

2026-11-17: Godot 앱의 타이틀, 실제 조작 안내, 클리어 결과 화면을 연결했습니다.

- 시작은 타이틀입니다. 플레이/이어하기, 처음 배우기(연습), 설정을 제공합니다.
- 처음 레벨 1을 시작하면 A 탭 → B 탭 → 자동 수집 관찰의 안내를 표시합니다. 다른 차량/배속/되돌리기/셔플은 안내 중 차단합니다. 안내 종료 후 자유 플레이할 수 있습니다.
- 기존 진행이 있으면 이어하기로 해당 상태를 복구합니다. 연습은 별도 코어 인스턴스를 사용하고 캠페인/구매/보상/레벨 완료 기록을 변경하지 않습니다. 연습 중 앱을 닫아도 캠페인 저장을 덮어쓰지 않습니다.
- 클리어는 연출 후 결과 화면에서 기다립니다. 다음 레벨 버튼을 눌러야 이동합니다. 클리어한 저장을 재실행해도 결과 화면으로 복귀할 수 있습니다.
- 마지막 레벨을 완료하면 처음부터 다시 플레이를 명시적으로 선택할 수 있으며 기존 완료 기록은 보존합니다.
- 타이틀·결과·일시정지·설정·상점·앱 비활성 상태에서 시뮬레이션과 차량 입력을 멈춥니다. 타이틀 복귀 시 현재 레벨을 저장합니다.
- 차량은 3D 게임판의 실제 출입구에 놓입니다. 목표 색 적재함에 현재 구슬과 적재 수, 차량 ID를 표시하며 해당 차량을 직접 탭합니다. 분리된 상태 카드는 사용하지 않습니다.
- 구슬이 차량에서 트랙으로 내려가고, 길을 순환하다 수집 가능한 같은 색 차량 안으로 들어갑니다. `Board3D.gd`의 조명·구체·그림자·연결로가 이 관계를 보여줍니다. 출발/도착 연출 중 시뮬레이션과 차량 탭을 잠깐 대기시키고, 일시정지 중 연출도 멈춥니다. 연출 줄이기에서는 이 전이 연출을 생략합니다.
- 각 차량의 lane에서 출발하도록 Godot과 웹 코어를 함께 수정했습니다. 기존 300레벨 배치·저장 포맷·2배속·상점 계약은 유지합니다. 이미 완성된 차량을 다시 누르던 level-167/283의 해법 탭을 1개씩 제거했습니다. 기존 세이브의 트랙 위치와 Undo 스냅샷은 그대로 유효합니다.

검증: `HeadlessTest.gd` 572개 검사, 300레벨의 60/120Hz·1x/2x 조합 1,200회 재생 통과. 타이틀 입력 차단, 설정, 잘못된 튜토리얼 탭 차단, 단계 진행, 연습 후 기존 코어/완료 기록 보존, 결과 대기/중복 입력 차단, 재실행 복원, 출발 위치와 수집 이벤트 검사를 포함합니다. `BoardRenderCheck.gd`는 세이브와 분리된 코어에서 실제 GPU 렌더로 출발·순환·수집·클리어까지 캡처하며 6대 배치도 확인합니다. `--practice` 실행 인수로 튜토리얼 연습에 바로 진입할 수 있습니다.

첨부 이미지는 흐름과 색상 가독성의 참고로 사용했습니다. 이미지의 원본 그래픽·코인 경제·광고 보상 배수는 이번 변경에 포함하지 않았습니다. 최종 아트 보강과 iOS 기기 레이아웃/터치 검증은 별도 단계입니다.
