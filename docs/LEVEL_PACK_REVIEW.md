# 20레벨 팩 검토 및 통합

Gemini 원본은 실행 검증되지 않은 초안이었습니다. 실제 규칙에 맞게 수정하고 재생한 팩만 통합했습니다.

## 수정

- level-016/017: 과잉인 yellow 두 개를 D/E 차량의 red/blue 부족분으로 교체했습니다.
- level-019: D/E의 blue 두 개를 각각 red/yellow 부족분으로 교체했습니다.
- level-020: D/E의 yellow 네 개를 red 두 개/blue 두 개로 교체했습니다.
- level-005의 트랙 용량은 2에서 4로, level-013/018은 4에서 6으로 조정했습니다. 기존 용량에서 해결되지 않는 배치의 병목을 완화했습니다.
- 원본의 반복 사출은 이미 완성된 차량을 다시 사출하는 경우가 있어 새 해법으로 교체했습니다. 실제 코어를 바꾸거나 블록을 임의 생성하지 않았습니다.
- 힌트는 수정된 배치에 맞추고, 단순히 A부터 끝까지 누르라는 안내 대신 수집 공간과 남길 목표 색을 관찰하도록 수정했습니다.

## 검증

- 로컬의 이벤트 기반 탐색으로 해법 후보를 찾았습니다. 탐색 결과를 최단 해법이나 불가능성의 수학적 증명으로 취급하지 않습니다.
- 실제 Godot GameCore로 모든 해법을 60/120Hz, 1x/2x에서 각각 재생해 80회 모두 통과했습니다.
- 각 사출 후 4.2초 대기하고 상태·색상별 총량·막힘·전체 클리어를 확인했습니다.
- 별도의 규칙/저장/컨트롤러/튜토리얼 회귀 검사 181개를 통과했습니다.
- 실제 Windows 화면에서 첫 안내와 차량 강조를 확인했습니다. 첫 5레벨 안내와 완료 기록을 저장하며 입력을 강제하지 않습니다.

이번 데이터 교체는 개발용 레벨 호환성 식별자를 바꾸므로 기존 두 레벨의 개발 세이브는 새 게임으로 시작합니다. 출시 세이브 마이그레이션은 별도 과제입니다.
해결 가능성과 UI 동작을 확인한 단계이며, 재미·체감 난이도·리텐션은 사람의 플레이테스트로 검증해야 합니다.
