CarLoop 다음 구현: 일시정지·설정·플레이 피드백

이 파일은 실제 Windows 저장소의 현재 소스 스냅샷이다.
Godot 4.7.2 네이티브 2D 게임이며 iOS를 먼저 출시하고 이후 Android를 지원한다.
20레벨, 첫 5레벨 튜토리얼, 힌트, 완료 기록과 로컬 저장이 이미 동작한다.
현재 181개 회귀 검사와 80회 Godot 레벨 재생을 통과했다.

이번 목표:
플레이 중 안전한 일시정지, 별도 저장되는 설정, 사출/수집/완성 피드백을 추가한다.
현재 소스를 읽고 필요한 파일만 변경해라. 새 게임을 다시 작성하지 않는다.
소스에 없는 외부 가이드나 HubGame 정책을 추정해서 추가하지 않는다.
광고/결제/리더보드/로그인/서버/HubGame/JavaScriptBridge는 이번 범위가 아니다.

수정 범위:
- 추가 가능: scripts/SettingsService.gd, scripts/FeedbackService.gd 및 필요한 소규모 테스트 파일.
- 수정 가능: scripts/Main.gd, scenes/Main.tscn, scripts/HeadlessTest.gd.
- TrackView.gd는 기존 렌더링 API를 이해하기 위한 참조이며 수정하지 않는다.
- GameManager.gd는 안전한 저장소 API 참조이며 변경하지 않는다.
- GameCore.gd, TutorialGuide.gd, 레벨/해법/튜토리얼 JSON, project.godot과 웹은 변경하지 않는다.
- 외부 애드온, 유료 자산, 폰트, 이미지, 오디오 파일 의존성을 추가하지 않는다.
- RefCounted 서비스와 Node/UI의 역할을 분리하고 코어 규칙에는 접근해 수정하지 않는다.

현재 API:
- core.update_progress(delta) -> {"moved": bool, "collected": bool}
- core.state -> levelIdx, speed, cars, track, cleared, history
- core.export_save()/is_valid_save(payload)/load_state(payload)
- guide.export_progress()/restore_progress(data)/mark_completed(level_id)
- Main의 _save는 코어 페이로드에 progress를 추가해 저장한다.
- GameManager의 save_progress(payload, validator)/load_progress(validator)는 정상 백업과 상태 검증을 지원한다.
- autoload 인스턴스의 configure_paths를 설정 저장용으로 바꾸면 실제 게임 세이브가 훼손되므로 금지한다.

1. 일시정지
- 사용자의 일시정지, 설정 창 열림, 운영체제의 suspended를 각각 구분한다.
- 셋 중 하나라도 활성 상태이면 코어 이동과 clear_timer가 진행되지 않는다.
- 재개 시 기존 skip_next_delta와 accumulator 초기화를 유지해 시간 점프를 막는다.
- 일시정지/설정 상태에서는 사출·Undo·Shuffle·다시하기·배속 변경을 UI와 핸들러 양쪽에서 막는다.
- 일시정지 해제/설정 닫기 버튼은 정상 작동하며 키보드/터치 입력이 뒤의 게임으로 새지 않는다.
- 설정을 닫으면 설정을 열기 전의 사용자 일시정지 상태를 유지한다.
- 앱 백그라운드->복귀로 사용자가 눌러 둔 일시정지가 풀리지 않아야 한다.
- 클리어 대기 중 일시정지하면 타이머를 보존하고 재개 후 한 번만 전환한다.
- 일시정지는 세션 상태이며 게임 재실행 시 영구적으로 멈춘 상태로 복원하지 않는다.
- 게임/튜토리얼/완료 기록의 기존 저장을 보존하고 일시정지/중단 시 필요한 저장도 수행한다.

2. 설정
- 효과음 sfx_enabled=true, 진동 haptics_enabled=true, 연출 줄이기 reduced_motion=false.
- 세 값은 반드시 bool로 검증하며 별도의 버전 있는 설정 파일에 저장한다.
- 기존 게임과 다른 경로인 user://carloop_settings.*를 사용한다.
- GameManager 스크립트의 별도 인스턴스를 전용 prefix로 생성해 재사용할 수 있다.
  별도 Node를 생성한다면 소유권/해제를 처리하고 autoload의 경로를 바꾸지 않는다.
- 변경은 즉시 반영·저장하고 손상된 설정은 백업 또는 기본값으로 복원한다.
- 설정 저장 실패로 게임을 멈추거나 정상 게임 저장을 초기화하지 않는다. 설정 UI에 실패를 알린다.
- 기존 정상 세이브에 설정 데이터가 없더라도 게임 진행/튜토리얼/완료 기록이 유지된다.

3. 소리·진동·시각 피드백
- 이벤트: 사출, 수집, 차량 완성, 레벨 완성, 막힘 진입.
- _process 또는 _refresh_status의 매 프레임 호출로 같은 소리가 계속 재생되지 않게 한다.
- 한 프레임 여러 블록 수집은 합치고 전체 완성 시 하위 효과가 과도하게 중첩되지 않게 한다.
- AudioStreamWAV를 사용하는 짧고 조용한 합성 효과음으로 임시 구현한다.
  PCM 포맷, 샘플레이트, 바이트 길이를 정확히 설정하고 짧은 페이드 인/아웃을 적용한다.
- AudioStreamPlayer를 이벤트마다 계속 생성하지 말고 작은 고정 풀을 사용한다.
- 음소거 전환과 앱 중단/일시정지는 재생 중인 소리도 정지시킨다.
- 진동은 사용자 설정을 따르고 iOS/Android에서만 호출한다. Windows/헤드리스에서는 안전한 no-op.
- 짧은 버튼/패널 강조처럼 작은 시각 피드백을 적용하고 reduced_motion이면 장식 Tween을 생략한다.
- reduced_motion은 코어 속도/트랙 블록 이동/클리어 판정/2배속에 영향을 주지 않는다.
- Undo/다시하기/레벨 전환/창 종료에서 오래된 Tween/효과가 다음 상태에 남지 않게 한다.
- 실제 iPhone 진동 품질과 오디오 세션/무음 스위치 동작은 Mac 실기기 미검증으로 명시한다.

4. UI
- 세로 화면과 SafeMargin, 현재 ScrollContainer를 유지한다.
- 기존 4개 상단 버튼에 무조건 버튼을 더해 가로로 넘치게 만들지 말고 별도 행/메뉴를 사용한다.
- 터치 대상은 최소 44 논리 픽셀, 설정 창은 작은 화면에서도 스크롤/닫기가 가능해야 한다.
- 튜토리얼 힌트, 강조, 완료 기록, 현재 레벨 다시하기가 기존대로 작동해야 한다.
- 개발용 내부 용어나 SDK 이름을 플레이어에게 표시하지 않는다.

5. 검사
- 기존 HeadlessTest의 실패 시 quit(1), 성공 시 quit(0)을 유지한다. 검사/조건을 삭제하거나 느슨하게 바꿔 통과시키지 않는다.
- 고정 fixture와 실제 레벨을 검사하는 기존 구분을 유지한다.
- 추가 검사: 일시정지 중 위치/클리어 타이머 불변, 재개 시간 점프 방지,
  설정 닫기 전후 사용자 일시정지 유지, 백그라운드 복귀 상태 유지,
  일시정지 중 게임 핸들러 차단, 설정 파일 분리/복원/손상 처리,
  음소거·진동 비활성·연출 줄이기가 게임 상태를 바꾸지 않는 것.
- 테스트는 임시 전용 저장 prefix를 사용하고 실제 사용자 설정/게임 세이브를 건드리지 않는다.
- 헤드리스에서 오디오 장치·모바일 진동·GPU가 없어도 검사가 종료되도록 한다.
- Windows 실행은 .\tools\godot.ps1 play, 전체 검사는 .\tools\godot.ps1 test다.
- 실제 Godot 실행 환경이 없으면 실행 검증했다고 쓰지 않는다.

출력:
1. 실제 확인한 코드와 설계 결정 8줄 이내.
2. 새 파일은 경로와 생략 없는 전체 코드.
3. 기존 파일은 정확한 문맥이 있는 unified diff로 제공한다. 파일 전체를 불필요하게 재출력하지 않는다.
4. 인라인 코드 주석, 미완성 placeholder, 생략 표시, 가상의 파일/시그널을 넣지 않는다.
5. 변경하지 않은 파일과 레벨 데이터는 출력하지 않는다.
6. 실제 실행한 검사와 미실행 검사, iOS 실기기 과제를 짧게 구분한다.
결과가 길면 파일 단위로 완성해서 나누어 제공해라.

func _ready() -> void:
	get_tree().auto_accept_quit = false
	resized.connect(_apply_safe_area)
	_apply_safe_area()
	var data: Variant = null
	var file := FileAccess.open("res://data/levels.json", FileAccess.READ)
	if file != null:
		data = JSON.parse_string(file.get_as_text())
		file.close()
	if not CoreScript.valid_levels(data):
		status_label.text = "레벨 데이터를 읽을 수 없습니다."
		_set_controls_enabled(false)
		set_process(false)
		return
	core = CoreScript.new(data)
	_load_tutorials()
	var saved: Dictionary = save_manager.load_progress(Callable(core, "is_valid_save"))
	if core.load_state(saved):
		status_message = "저장한 게임을 이어갑니다."
		if guide != null:
			guide.restore_progress(saved.get("progress"))
		if save_manager.restored_from_backup:
			save_message = "백업에서 진행 상황을 복구했습니다."
	track_view.configure(core)
	_render_static()
	_refresh_status()

func _set_controls_enabled(enabled: bool) -> void:
	for control in $SafeMargin/Scroll/VBox/Header/Controls.get_children():
		control.disabled = not enabled

func _apply_safe_area() -> void:
	if not is_node_ready():
		return
	var insets := Vector4.ZERO
	if OS.has_feature("ios") or OS.has_feature("android"):
		var safe := DisplayServer.get_display_safe_area()
		if safe.size.x > 0 and safe.size.y > 0:
			var screen_to_view := get_viewport().get_screen_transform().affine_inverse()
			var bounds := get_viewport_rect()
			var usable := Rect2(screen_to_view * Vector2(safe.position), screen_to_view * Vector2(safe.end) - screen_to_view * Vector2(safe.position)).intersection(bounds)
			if usable.has_area():
				insets = Vector4(usable.position.x, usable.position.y, bounds.end.x - usable.end.x, bounds.end.y - usable.end.y)
	for index in range(4):
		safe_margin.add_theme_constant_override(["margin_left", "margin_top", "margin_right", "margin_bottom"][index], 16 + int(ceil(maxf(0.0, insets[index]))))

func _notification(what: int) -> void:
	if what in [NOTIFICATION_APPLICATION_FOCUS_OUT, NOTIFICATION_APPLICATION_PAUSED]:
		suspended = true
		_save(true)
	elif what in [NOTIFICATION_APPLICATION_FOCUS_IN, NOTIFICATION_APPLICATION_RESUMED]:
		suspended = false
		skip_next_delta = true
		if core != null:
			core.accumulator = 0.0
		if is_node_ready():
			_apply_safe_area()
	elif what == NOTIFICATION_WM_CLOSE_REQUEST:
		_save(true)
		get_tree().quit()

func _save(force: bool = false) -> void:
	if core == null or not dirty:
		return
	var now := Time.get_ticks_msec()
	if not force and now - last_save_time < 1000:
		return
	last_save_time = now
	var payload: Dictionary = core.export_save()
	if guide != null:
		payload["progress"] = guide.export_progress()
	if save_manager.save_progress(payload, Callable(core, "is_valid_save")):
		dirty = false
		save_message = "진행 상황 자동 저장 중"
	else:
		save_message = "저장할 수 없습니다. 현재 게임은 계속할 수 있습니다."
	save_label.text = save_message

func _process(delta: float) -> void:
	if core == null or suspended:
		return
	if skip_next_delta:
		skip_next_delta = false
		return
	if clear_timer >= 0.0:
		clear_timer = maxf(0.0, clear_timer - minf(delta, 0.1))
		if clear_timer == 0.0:
			clear_timer = -1.0
			if guide != null:
				guide.mark_completed(core.levels[core.state["levelIdx"]]["id"])
			var next_index: int = (int(core.state["levelIdx"]) + 1) % core.levels.size()
			core.init_level(next_index, int(core.state["speed"]))
			status_message = "%d레벨을 완료했습니다! 처음부터 다시 즐길 수 있습니다." % core.levels.size() if next_index == 0 else "다음 레벨입니다."
			dirty = true
			_save(true)
			_render_static()
		return
	var result: Dictionary = core.update_progress(delta)
	if result["moved"]:
		dirty = true
		track_view.queue_redraw()
	if result["collected"]:
		_render_cars()
	_save(result["collected"])
	_refresh_status()

func _refresh_status() -> void:
	capacity_label.text = "Track %d / %d" % [core.state["track"].size(), core.levels[core.state["levelIdx"]]["trackCapacity"]]
	if core.is_cleared():
		status_label.text = "클리어! 다음 레벨로 넘어갑니다."
		if clear_timer < 0.0:
			clear_timer = 1.2
	elif core.check_deadlock():
		status_label.text = "막힘 상태입니다. Undo 또는 Reset을 사용하세요."
	else:
		status_label.text = status_message

func _render_static() -> void:
	var level: Dictionary = core.levels[core.state["levelIdx"]]
	level_label.text = "%d / %d · %s" % [int(core.state["levelIdx"]) + 1, core.levels.size(), level.get("name", level["id"])]
	_refresh_tutorial()
	speed_button.text = str(core.state["speed"]) + "x"
	save_label.text = save_message
	_render_cars()
	track_view.queue_redraw()

func _render_cars() -> void:
	for child in cars_box.get_children():
		cars_box.remove_child(child)
		child.queue_free()
	for car in core.state["cars"]:
		var button := Button.new()
		var complete: bool = core.state["cleared"].has(car["id"])
		var blocks := PackedStringArray()
		for color in car["blocks"]:
			blocks.append(String(color).left(1).to_upper())
		button.text = "%s · %s  %s\n앞 → %s → 뒤" % [car["id"], car["color"], "CLEARED" if complete else "%d/%d" % [car["blocks"].size(), car["capacity"]], "  ".join(blocks) if not blocks.is_empty() else "empty"]
		button.custom_minimum_size = Vector2(0, 80)
		var style := StyleBoxFlat.new()
		style.bg_color = Color("#e0f5e8") if complete else Color("#ffffff")
		style.border_color = TrackScript.color_for(car["color"])
		var highlight := false
		if guide != null and hint_visible and core.state["history"].is_empty():
			highlight = guide.lesson(level_id()).get("focusCarId") == car["id"]
		style.set_border_width_all(5 if highlight else 2)
		if highlight:
			button.text = "▶ " + button.text
		style.set_corner_radius_all(12)
		for style_name in ["normal", "hover", "pressed", "disabled", "focus"]:
			button.add_theme_stylebox_override(style_name, style)
		button.add_theme_color_override("font_color", TrackScript.color_for(car["color"]).darkened(0.4))
		for color_name in ["font_hover_color", "font_pressed_color", "font_focus_color"]:
			button.add_theme_color_override(color_name, TrackScript.color_for(car["color"]).darkened(0.4))
		button.add_theme_color_override("font_disabled_color", Color("#536375"))
		button.disabled = car["locked"] or complete or car["blocks"].is_empty()
		button.pressed.connect(_on_car_pressed.bind(String(car["id"])))
		cars_box.add_child(button)
	undo_button.disabled = core.state["history"].is_empty()

func _on_car_pressed(car_id: String) -> void:
	if core == null:
		return
	var result: String = core.launch_car(car_id)
	if result == "launched":

extends Node

const DEFAULT_PREFIX := "user://carloop_save"
var save_path: String
var temp_path: String
var backup_path: String
var restored_from_backup := false

func _init(prefix: String = DEFAULT_PREFIX) -> void:
	configure_paths(prefix)

func configure_paths(prefix: String) -> void:
	save_path = prefix + ".json"
	temp_path = prefix + ".tmp"
	backup_path = prefix + ".bak"

func _read_file(path: String) -> Variant:
	var file := FileAccess.open(path, FileAccess.READ)
	if file == null or file.get_length() > 4194304:
		return null
	var content := file.get_as_text()
	file.close()
	var parser := JSON.new()
	if parser.parse(content) != OK:
		return null
	return parser.data

func _accepted(data: Variant, validator: Callable) -> bool:
	return data is Dictionary and validator.is_valid() and validator.call(data) == true

func _rename(source: String, target: String) -> Error:
	return DirAccess.rename_absolute(ProjectSettings.globalize_path(source), ProjectSettings.globalize_path(target))

func _remove(path: String) -> Error:
	return DirAccess.remove_absolute(ProjectSettings.globalize_path(path))

func load_progress(validator: Callable) -> Dictionary:
	restored_from_backup = false
	var primary: Variant = _read_file(save_path)
	if _accepted(primary, validator):
		return primary
	var backup: Variant = _read_file(backup_path)
	if _accepted(backup, validator):
		restored_from_backup = true
		return backup
	return {}

func save_progress(runtime_state: Dictionary, validator: Callable) -> bool:
	if not _accepted(runtime_state, validator):
		return false
	var directory_error := DirAccess.make_dir_recursive_absolute(ProjectSettings.globalize_path(save_path.get_base_dir()))
	if directory_error != OK:
		return false
	var file := FileAccess.open(temp_path, FileAccess.WRITE)
	if file == null:
		return false
	file.store_string(JSON.stringify(runtime_state))
	file.flush()
	var write_error := file.get_error()
	file.close()
	if write_error != OK or not _accepted(_read_file(temp_path), validator):
		return false
	var primary_valid := _accepted(_read_file(save_path), validator)
	if primary_valid:
		if FileAccess.file_exists(backup_path) and _remove(backup_path) != OK:
			return false
		if _rename(save_path, backup_path) != OK:
			return false
	elif FileAccess.file_exists(save_path) and _remove(save_path) != OK:
		return false
	if _rename(temp_path, save_path) != OK:
		if FileAccess.file_exists(backup_path) and not FileAccess.file_exists(save_path):
			DirAccess.copy_absolute(ProjectSettings.globalize_path(backup_path), ProjectSettings.globalize_path(save_path))
		return false
	return true

extends Control

var core

func _ready() -> void:
	mouse_filter = Control.MOUSE_FILTER_IGNORE
	resized.connect(queue_redraw)

func configure(next_core: RefCounted) -> void:
	core = next_core
	queue_redraw()

static func color_for(color: String) -> Color:
	return {"red": Color("#ef6464"), "blue": Color("#478ee8"), "yellow": Color("#f6bd35")}.get(color, Color.GRAY)

func _draw() -> void:
	if core == null:
		return
	var level: Dictionary = core.levels[core.state["levelIdx"]]
	var nodes: Array = level["trackNodes"]
	var extent := Vector2.ONE
	for point in nodes:
		extent.x = maxf(extent.x, float(point[0]))
		extent.y = maxf(extent.y, float(point[1]))
	var positions := PackedVector2Array()
	for point in nodes:
		positions.append(Vector2(40, 48) + Vector2(float(point[0]), float(point[1])) / extent * (size - Vector2(80, 88)).max(Vector2.ONE))
	var path := positions.duplicate()
	path.append(positions[0])
	draw_style_box(_panel_style(), Rect2(Vector2.ZERO, size))
	draw_polyline(path, Color("#ccd8e8"), 5.0, true)
	for index in range(positions.size()):
		draw_circle(positions[index], 10.0, Color("#dfe8f5"))
		for car in level["cars"]:
			if int(car["lane"]) % nodes.size() == index:
				draw_string(ThemeDB.fallback_font, positions[index] + Vector2(-8, -18), car["id"], HORIZONTAL_ALIGNMENT_LEFT, -1, 20, color_for(car["color"]))
	for item in core.state["track"]:
		var progress := float(item["progress"])
		var index := int(progress)
		var position := positions[index].lerp(positions[(index + 1) % positions.size()], progress - index)
		draw_circle(position, 18.0, color_for(item["color"]))
		draw_string(ThemeDB.fallback_font, position + Vector2(-6, 6), String(item["color"]).left(1).to_upper(), HORIZONTAL_ALIGNMENT_LEFT, -1, 18, Color("#14253b"))

func _panel_style() -> StyleBoxFlat:
	var style := StyleBoxFlat.new()
	style.bg_color = Color("#f7faff")
	style.set_corner_radius_all(20)
	return style
