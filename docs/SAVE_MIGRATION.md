# Godot 세이브 마이그레이션

2026-11-17. Windows Godot 4.7.2에서 구현·검증했습니다. 게임 파일 저장은 v5이며 코어 규칙과 HTML 프로토타입의 저장 형식은 변경하지 않았습니다.

## 업데이트 동작

| 변경 | 복원 결과 |
| --- | --- |
| 레벨 추가·삽입·재정렬 | ID로 현재 레벨을 찾아 보드·이동 위치·배속·Undo 복원 |
| 이름·레벨 메타데이터 변경 | 보드 유지 |
| 현재 레벨의 차량/블록·트랙 규칙 변경 | 현재 레벨만 다시 시작, 배속·안내 확인·완료 기록 유지 |
| 현재 레벨 삭제 | 이전 순서에서 다음 생존 레벨, 없으면 첫 미완료, 모두 완료했으면 첫 레벨 |
| 과거 완료 레벨 삭제 후 재등장 | 삭제 중에도 ID 기록을 보관하여 재등장 시 확인/완료 상태 유지 |
| 주 파일 손상 | 유효한 백업 복원, 손상 파일로 백업을 덮어쓰지 않음 |
| 미지원 버전·출처 불명의 v4 해시 | 주 파일·백업·임시 파일 보존, 게임 저장/건너뛰기 사용 차단 및 화면 안내 |

이동 중인 블록과 Undo도 원래 레벨 정의로 검증한 뒤 변환합니다. 데이터가 손상되면 규칙 변경으로 간주해 조용히 초기화하지 않습니다. 변환 자체가 라이브 상태를 바꾸지 않으며, 검증된 결과만 컨트롤러에 적용합니다.

## 파일 구조와 쓰기

`user://carloop_save.{json,tmp,bak}`를 사용합니다. v5는 `level`(원래 레벨 정의), `levelSignature`(게임 규칙의 SHA-256), `levelOrder`(저장 당시 ID 순서), `state`, `progress`를 포함합니다. 파일 안의 현재 레벨/Undo 인덱스는 0입니다. 현재 카탈로그 인덱스는 로드할 때 ID로 결정합니다.

규칙 서명은 레벨 ID·트랙 용량/노드·차량 정의를 사용합니다. 정수와 정수값 실수, 사전 키 순서 차이는 정규화합니다. 레벨 이름과 레벨 단위 부스터 표시 메타데이터는 제외합니다. 차량 배열 순서와 차선은 규칙 변경으로 취급합니다. ID는 출시 후 다른 퍼즐에 재사용하지 마세요.

정상 변환 후 즉시 `.tmp` 작성·재검증·백업·교체 순서를 거칩니다. 쓰기가 실패하면 기존 파일을 유지하고 재시도합니다. 성공한 첫 변환은 기존 정상 v4를 `.bak`으로 남깁니다. 이후 일반 저장에서는 직전 정상 저장으로 백업이 순환하므로 영구 아카이브는 아닙니다.

주 파일 또는 백업에 미지원 데이터가 있으면 자동 저장을 차단합니다. 사용 가능한 백업이 있으면 그 상태로 세션을 시작할 수 있지만 파일은 갱신하지 않습니다. 복원 가능한 백업이 없으면 기본 보드로 시작하며 저장되지 않음을 표시합니다. 미확인 카탈로그의 인덱스로 레벨 ID를 추정하지 않습니다. 원본을 확보하고 별도 호환 변환을 추가해야 합니다.

설정 v2와 상점 지갑 v1은 기존 파일/스키마를 유지합니다. 게임 저장이 차단되면 건너뛰기 예약을 소비하거나 환불하지 않습니다. 미처리 예약이 있으면 해결될 때까지 게임은 일시정지됩니다. 별도의 구매/광고 SDK나 서버를 추가하지 않았습니다.

## 구버전 지원 범위

v4 전체 카탈로그 해시를 현재 데이터 및 `godot-project/data/save_catalogs_v4.json`에 등록한 원본과 비교합니다. 레지스트리는 다음 원본 배열을 보관하며 해시는 Godot의 실제 JSON 직렬화로 계산합니다.

1. `godot-project/tests/fixtures/reference_levels.json`의 최초 2레벨.
2. `docs/handoffs/gemini-pacing-review-input.txt`의 변경 전 20레벨.
3. `godot-project/data/campaign_seed.json`의 검토 완료 20레벨.

현재 300레벨의 v4도 자동 인식합니다. 원본이 다른 v4는 새 카탈로그를 레지스트리에 추가하고 검사해야 합니다. v1~v3·미래 버전·웹 세이브의 임의 변환은 지원하지 않습니다. v5 이후의 레벨 변경은 전체 구버전 카탈로그 보관 없이 파일 자체의 원래 레벨 정의로 처리합니다.

## 검증과 Mac 인계

`.\tools\godot.ps1 test`에 `MigrationTest.gd`를 포함했습니다. 격리된 `user://migration_tests_*` 경로를 사용하고 이번 실행 파일을 정리합니다. 마이그레이션 112개 검사, 기존 게임/컨트롤러 553개, 상점 43개를 통과했습니다. 통합 검사는 300레벨의 60/120Hz·1x/2x 해법도 재생합니다.

변환 검사에는 실제 Main 씬의 v4→v5 자동 저장/재시작, 이동/Undo/새 블록 ID, 콘텐츠 변경, 손상 검증, 원본 백업, 쓰기 실패, 미지원 데이터의 세 파일 보존, 안내/완료 기록, 설정과 예약된 보상 보존을 포함했습니다.

Mac에서는 앱 업데이트 설치 전후의 실제 `user://` 유지, 저장 중 앱 중단/재실행과 디스크 오류 복구를 추가 확인해야 합니다. 자동 검사는 iOS 파일 시스템·전원 손실 시험을 대체하지 않습니다. 클라우드 동기화·기기 간 이동·앱 삭제 후 복구는 이번 로컬 마이그레이션 범위에 포함하지 않습니다.
