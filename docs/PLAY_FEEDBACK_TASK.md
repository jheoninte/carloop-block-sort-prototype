# 일시정지·설정·플레이 피드백

## 작업 상태

현재 300레벨, 일시정지·설정, 원본 음원 12개·배경 음악·음량 믹스와 링/입자 연출을 통합했습니다. 최신 현황과 검증은 `docs/LAUNCH_CONTENT_AUDIO_COMMERCE.md`에 있습니다. 아래 결과는 최초 피드백 통합 당시의 기록입니다.

`docs/handoffs/gemini-pause-feedback-input.txt`는 완료된 요청의 소스 스냅샷입니다. 후속 Gemini 요청에는 현재 파일을 새로 제공해야 합니다.

## 구현 및 검증 결과

- 사용자 일시정지·설정 열림·OS 중단을 별도 상태로 관리합니다. 이동과 클리어 대기가 정지하고 재개 첫 프레임의 경과 시간을 건너뜁니다.
- 일시정지 메뉴에서도 설정에 접근합니다. 모달 뒤 차량·배속·Undo·Shuffle·다시하기·힌트를 차단하고 Escape로 닫기/재개합니다.
- `SettingsService.gd`는 효과음·진동·연출 줄이기를 별도 검증 가능한 JSON과 백업으로 저장합니다. 저장 실패 시 현재 세션에는 적용합니다.
- `FeedbackService.gd`는 고정 4개 플레이어와 5개 합성 음원을 사용합니다. 수집은 80ms 간격으로 제한하며 동일 프레임의 레벨/차량 완성을 우선합니다.
- 취소·재시작·연출 줄이기·앱 중단 시 효과를 정리하고 원래 크기와 피벗을 복원합니다. 진동은 iOS/Android에서만 호출합니다.
- 자동 검사 254개와 20레벨의 60/120Hz·1x/2x 재생 80회를 통과했습니다. 테스트 게임과 설정 저장은 사용자 파일과 분리합니다.
- Windows 화면에서 일시정지 메뉴, 일시정지 중 설정 접근, 옵션 토글, 설정 종료 후 일시정지 유지도 확인했습니다.
- iOS 진동 강도, 오디오 세션, 무음 스위치와 실제 기기 안전 영역은 Mac 실기기에서 검증해야 합니다.

## 완료 조건

- 사용자 일시정지, 설정 열림, 운영체제 중단을 구분하고 이동과 클리어 타이머를 안전하게 정지/재개합니다.
- 설정 창을 닫거나 앱이 복귀해도 사용자가 눌러 둔 일시정지를 유지합니다.
- 효과음/진동/연출 줄이기를 별도 로컬 설정 파일에 저장합니다. 게임 세이브와 튜토리얼 완료 기록을 보존합니다.
- 사출·수집·차량/레벨 완성·막힘 진입에 한 번씩 작은 피드백을 제공합니다. 중복/과도한 재생을 제한합니다.
- 외부 SDK/자산 없이 임시 합성 효과음과 플랫폼별 진동을 사용하고, 음소거와 연출 줄이기가 코어 규칙을 바꾸지 않습니다.
- 기존 181개 검사와 80회 Godot 레벨 재생을 유지하고 중단/설정/피드백 검사를 추가합니다.
- iOS 진동/오디오 세션/무음 스위치는 Mac 실기기 단계에 남은 검증으로 구분합니다.
